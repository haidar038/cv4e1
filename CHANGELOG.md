yang tidak perlu. Riwayat kerja per sesi (untuk pengembang dan agen AI) ada di
`plans/cv4every1-changelog.md`.

Aturan file ini (`release-process.md` §5):

- Selalu sebutkan perubahan schema dan dampaknya ke file ekspor lama.
- Selalu sebutkan bila file ekspor lama terpengaruh.
- Tanpa klaim yang tidak bisa diverifikasi: tanpa "dijamin lolos ATS",
  tanpa skor CV.
